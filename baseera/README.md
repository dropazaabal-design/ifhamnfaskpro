# بصيرة

منصّة اختبارات نفسية ومعرفية عربية، مبنيّة على مقاييس منشورة، وتعرض مع كل نتيجة هامش خطئها وما لا يستطيع الاختبار قوله.

موقع ثابت بالكامل (Astro): كل صفحة HTML جاهز، والتصحيح في متصفّح الزائر، ولا خادم ولا قاعدة بيانات.

## التشغيل

```bash
npm install
npm run dev       # معاينة محلّية
npm run verify    # الفحص العلمي ← البناء ← فحص SEO
```

`npm run verify` يُسقط البناء إن غاب عن أيّ اختبار مصدره أو ثباته أو قائمة حدوده، أو إن بلغ تصحيحه غير طرفَي مقياسه، أو إن وُجد رابط داخلي مكسور أو صفحة بلا وصف أو canonical.

## النشر

الناتج في `dist/` ملفّات ثابتة تُرفع إلى أيّ استضافة: Cloudflare Pages أو Netlify أو Vercel (مجّاناً)، أو أيّ خادم.

- أمر البناء: `npm run build` · مجلّد الناتج: `dist`
- غيّر العنوان في `src/config.ts` **و** `astro.config.mjs` معاً (canonical وخريطة الموقع وصور المعاينة تُبنى منه).

## قبل الإطلاق: ما يحتاج قرارك أو مراجعتك

**١ — خمس عشرة قيمة ثبات لم تُراجَع في مصدرها.** `npm run check:science` يطبعها كلّها. هي قيم من الأدبيات، معلَّمة «تقدير» في صفحة المنهجية للزوّار. راجع كلّاً منها في الورقة الأصلية وحوّل `verified` إلى `true`.

**٢ — الترجمات العربية ترجمة المنصّة.** لأغلب المقاييس ترجمات عربية مُحكَّمة منشورة (IPIP وGAD-7 وروزنبرغ لها ترجمات موثّقة). استبدالها بالمُحكَّمة يرفع الثقة، ويحوّل `translation` إلى `validated`.

**٣ — AdSense.** ضع معرّف الناشر ومعرّفات الوحدات في `src/config.ts`. يُولَّد `ads.txt` تلقائياً، وتظهر الوحدات بمساحات محجوزة. فعّل رسالة الموافقة للمنطقة الأوروبية من لوحة AdSense (الخصوصية والرسائل) — لا يحتاج كوداً.

**٤ — البريد والحسابات.** `contactEmail` و`twitter` في `src/config.ts`.

## ما لم يُنشر، ولماذا

٤١ اختباراً في الخطّة، ١١ منشوراً. الأسباب في `src/data/catalog.ts` وصفحة `/methodology/`:

- **يحتاج إذناً:** مقياس الأشخاص الحسّاسين (آرون)، ومتلازمة المحتال (كلانس)، وجودة النوم (PSQI)، ومقاييس المماطلة (ستيل) للاستخدام التجاري.
- **لا مقياس علمي له:** «قيادي أم تنفيذي»، «نمط التفكير»، «عقلية الثراء» وغيرها. نفضّل ألّا ننشرها على أن نخترع أسئلة ونسمّيها علماً.
- **قيد الإعداد:** من مقاييس في الملك العام.

## ميزان الثقة

ثلاثة أشياء مع كل نتيجة، مشروحة للزائر في `/methodology/`:

1. **نطاق الثقة ٩٠٪** — `SEM = SD × √(1 − α)` من ثبات المقياس المنشور (`src/lib/scoring.ts`).
2. **جودة الإجابات** — السرعة، والسلسلة الطويلة، والموافقة على النقيضين (`src/lib/quality.ts`).
3. **التغيّر الموثوق** — مؤشّر Jacobson & Truax (1991) بين مرّتين محفوظتين، ولا يحكم إن كانت إحدى المرّتين متسرّعة (`src/lib/profile.ts`).

## البنية

```
src/
  config.ts              العنوان، AdSense، المتجر، كود الخصم
  data/tests/*.ts        الاختبارات: البنود، المقاييس، المصادر، المحتوى
  data/catalog.ts        الأربعون مدخلاً وأسباب التأجيل
  data/products.ts       المنتجات الرقمية وروابط UTM
  lib/                   التصحيح، الجودة، الملفّ، SEO، صور المعاينة
  scripts/runner.ts      مشغّل الاختبار في المتصفّح
tools/
  check-science.mjs      الفحص العلمي (يسبق البناء)
  check-seo.mjs          فحص الموقع المبني
```

## إضافة اختبار

انسخ ملفّاً من `src/data/tests/`، واملأ حقوله، وسجّله في `src/data/tests/index.ts`، وحوّل حالته في الكتالوج إلى `live`، ثم `npm run verify`. الفحص العلمي سيخبرك بكل ما ينقص.
