# بصيرة

منصّة اختبارات نفسية ومعرفية عربية، بمصدر معلن لكل اختبار، وتعرض هامش الخطأ حين يُعرف وما لا يستطيع الاختبار قوله.

موقع ثابت بالكامل (Astro): كل صفحة HTML جاهز، والتصحيح في متصفّح الزائر، ولا خادم ولا قاعدة بيانات.

## التشغيل

```bash
npm install
npm run dev       # معاينة محلّية
npm run verify    # الفحص العلمي ← البناء ← فحص SEO
```

`npm run verify` يُسقط البناء إن غاب عن أيّ اختبار مصدره أو ثباته أو قائمة حدوده، أو إن بلغ تصحيحه غير طرفَي مقياسه، أو إن وُجد رابط داخلي مكسور أو صفحة بلا وصف أو canonical.

## النشر

الناتج في `dist/` ملفّات ثابتة تُرفع إلى أيّ استضافة: Cloudflare Pages أو Netlify أو Vercel (مجّاناً)، أو أيّ خادم.

- أمر البناء: `npm run build` · مجلّد الناتج: `dist`
- غيّر العنوان في `src/config.ts` **و** `astro.config.mjs` معاً (canonical وخريطة الموقع وصور المعاينة تُبنى منه).

## قبل الإطلاق: ما يحتاج قرارك أو مراجعتك

**1 — قيم لم تُراجَع في مصدرها.** `npm run check:science` يطبعها كلّها: قيم ثبات أو انحراف من الأدبيات، وبنود أصلية لم تُجرَّب بعد. كلّها معلَّمة «تقدير» أو «غير معايَر» في صفحة المنهجية للزوّار. راجع كلّاً منها في الورقة الأصلية وحوّل `verified` إلى `true`.

أوجه IPIP-NEO-120 العشرون المستخدمة في عشرة اختبارات مُتحقَّق منها: الثبات من موقع IPIP، والانحراف محسوب من بيانات Johnson المنشورة على OSF (`src/data/ipip120.ts`).

**2 — الترجمات العربية ترجمة المنصّة.** لأغلب المقاييس ترجمات عربية مُحكَّمة منشورة (IPIP وGAD-7 وروزنبرغ لها ترجمات موثّقة). استبدالها بالمُحكَّمة يرفع الثقة، ويحوّل `translation` إلى `validated`.

**3 — AdSense.** ضع معرّف الناشر ومعرّفات الوحدات في `src/config.ts`. يُولَّد `ads.txt` تلقائياً، وتظهر الوحدات بمساحات محجوزة. فعّل رسالة الموافقة للمنطقة الأوروبية من لوحة AdSense (الخصوصية والرسائل) — لا يحتاج كوداً.

**4 — البريد والحسابات.** `contactEmail` و`twitter` في `src/config.ts`.

## ما لم يُنشر، ولماذا

41 في الخطّة: 32 اختباراً منشوراً وأداتان، و7 مؤجّلة. الأسباب في `src/data/catalog.ts` وصفحة `/methodology/`:

- **يحتاج إذناً أو لم يُحسم ترخيصه:** متلازمة المحتال (كلانس)، وجودة النوم (PSQI وRU-SATED)، والمماطلة (ستيل)، والتوازن بين العمل والحياة (مقاييس صراع العمل والأسرة)، والشخصية المالية (مقياس المقتِّر والمبذِّر لم يُتحقَّق من نصّه).
- **لا مقياس علمي له:** «عقلية الثراء» و«أسلوب الادّخار». نفضّل ألّا ننشرها على أن نخترع أسئلة ونسمّيها علماً.

ما نُشر بلا مقياس سمة يقول ذلك في صفحته: أسئلة الاستدلال والانحيازات بنود أصلية أو نماذج بحثية بلا ثبات منشور، والمهامّ التفاعلية (مدى الأرقام وSART) نسخ غير مقنّنة. لا نطاق ثقة لها ولا مقارنة بالناس.

## ميزان الثقة

ثلاثة أشياء مع كل نتيجة، مشروحة للزائر في `/methodology/`:

1. **نطاق الثقة 90%** — `SEM = SD × √(1 − α)` من ثبات المقياس المنشور (`src/lib/scoring.ts`).
2. **جودة الإجابات** — السرعة، والسلسلة الطويلة، والموافقة على النقيضين (`src/lib/quality.ts`).
3. **التغيّر الموثوق** — مؤشّر Jacobson & Truax (1991) بين مرّتين محفوظتين، ولا يحكم إن كانت إحدى المرّتين متسرّعة (`src/lib/profile.ts`).

## البنية

```
src/
  config.ts              العنوان، AdSense، المتجر، كود الخصم
  data/tests/*.ts        الاختبارات: البنود، المقاييس، المصادر، المحتوى
  data/ipip120.ts        أوجه IPIP-NEO-120 المشتركة: البنود والثبات والانحراف المتحقَّق منها
  data/reasoning.ts      ما تشترك فيه اختبارات الاستدلال الأصلية
  data/tools/*.ts        الأداتان: حاسبة الراتب، والقيم الأساسية
  data/catalog.ts        الواحد والأربعون مدخلاً وأسباب التأجيل
  data/products.ts       المنتجات الرقمية وروابط UTM
  lib/                   التصحيح، الجودة، الملفّ، SEO، صور المعاينة
  scripts/runner.ts      مشغّل الاختبار في المتصفّح
  scripts/tasks.ts       المهمّتان التفاعليتان: مدى الأرقام وSART
tools/
  check-science.mjs      الفحص العلمي (يسبق البناء)
  check-seo.mjs          فحص الموقع المبني
```

## إضافة اختبار

انسخ ملفّاً من `src/data/tests/`، واملأ حقوله، وسجّله في `src/data/tests/index.ts`، وحوّل حالته في الكتالوج إلى `live`، ثم `npm run verify`. الفحص العلمي سيخبرك بكل ما ينقص.
