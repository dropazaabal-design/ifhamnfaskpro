# بكج افهم نفسك — صفحة البيع

صفحة هبوط من ملف واحد (`index.html`) تبيع «بكج افهم نفسك» وتحوّل الزائر إلى
صفحة الدفع على Buy Me a Coffee.

افتح `index.html` مباشرة في المتصفّح للمعاينة — ما تحتاج أي أدوات بناء.

---

## ⚙️ لوحة التحكّم

كل اللي تحتاج تعدّله موجود في **أول السكربت** في نهاية `index.html`
(ابحث عن `لوحة التحكّم`):

| المتغيّر | وش يسوي |
|---|---|
| `BUY_URL` | رابط الشراء على Buy Me a Coffee |
| `DEADLINE` | تاريخ انتهاء سعر الإطلاق — يغذّي كل العدّادات في الصفحة |
| `REVIEWS` | آراء المشترين. فاضية = قسم الآراء مخفي تمامًا |
| `SAMPLE_URL` | رابط خلاصة مجانية للتجربة. فاضي = الزر مخفي |

### العدّاد (`DEADLINE`)

```js
const DEADLINE = "2026-10-15T23:59:59+03:00";
```

العدّاد **ما يعيد نفسه**. لما يوصل التاريخ يختفي من الصفحة كلها تلقائيًا،
والموعد مكتوب صراحة جنب العدّاد عشان يكون قابلًا للتحقق.

> ⚠️ **التزم بالتاريخ.** لما ينتهي، ارفع السعر فعلًا لـ150 أو حدّث التاريخ هنا.
> العدّاد اللي يرجع لنفسه كل زيارة يُكتشف بسرعة ويحرق ثقة العميل.

### الآراء (`REVIEWS`)

```js
const REVIEWS = [
  { t: "نص الرأي كما وصلك", n: "الاسم", m: "المدينة أو وصف مختصر", s: 5 },
];
```

القسم مخفي ما دامت المصفوفة فاضية. أول ما تضيف رأيًا واحدًا يظهر القسم،
ويُضاف تقييم مجمّع (`AggregateRating`) لبيانات جوجل المنظّمة تلقائيًا.

> ⚠️ **آراء حقيقية فقط.** التقييم المجمّع يروح لجوجل، والآراء المفبركة
> مخالفة لسياسات جوجل وتضرّ أكثر مما تنفع.

### الخلاصة المجانية (`SAMPLE_URL`)

حط رابط PDF لخلاصة واحدة كاملة، ويظهر زر «اقرأ خلاصة كاملة مجانًا» تحت زر
الشراء في الواجهة. أقوى أداة لكسر التردّد: يشوف جودة المنتج قبل ما يدفع.

## 📊 قياس النتائج

الصفحة ترسل أحداثًا لـ Google Analytics (المعرّف `G-TRQ306ZZPQ`) وتدفعها كمان
لـ `dataLayer` لو تستخدم Google Tag Manager.

| الحدث | متى يُرسل |
|---|---|
| `view_item` | فتح الصفحة |
| `scroll_depth` | 25% · 50% · 75% · 90% |
| `section_view_*` | ظهور قسم مفصلي (الواجهة، المشكلة، الاختبار، المقارنة، الحساب، العرض، الأسئلة) |
| `quiz_answer` | اختيار محور في «من وين تبدأ؟» |
| `volume_open` / `faq_open` | فتح مجلد من القائمة أو سؤال |
| `golden_rule_next` | تصفّح القواعد الذهبية |
| `begin_checkout` | فتح نافذة الدفع — مع `cta_location` |
| `checkout_redirect` | الانتقال فعليًا لصفحة الدفع |
| `checkout_abandon` | إغلاق النافذة بلا شراء |
| `exit_intent_shown` / `_dismiss` | نافذة المغادرة |
| `time_on_page` | 15 · 45 · 120 · 300 ثانية |

**أهم رقمين تتابعهما:**

1. `begin_checkout ÷ view_item` → نسبة من وصل لنيّة الشراء.
2. `checkout_redirect ÷ begin_checkout` → نسبة من كمّل بعد ما فتح النافذة.

وخاصية `cta_location` تقول لك أي زر يبيع فعلًا: `hero` · `quiz` · `mid_list` ·
`mid_math` · `deal` · `final` · `sticky` · `header` · `exit`. احذف الأزرار
الميتة وكرّر اللي يشتغل.

> Buy Me a Coffee ما ترجّع بيانات الشراء للصفحة، فما يمكن قياس `purchase`
> آليًا. قارن `checkout_redirect` بعدد الطلبات في لوحة BMC يدويًا عشان تطلع
> بنسبة الإغلاق الحقيقية.

## 🧱 بنية الصفحة

الترتيب مقصود: كل قسم يجاوب على الاعتراض اللي يجي بعد اللي قبله.

1. **الواجهة** — الوعد + السعر + العدّاد + زر الشراء
2. **الأرقام** — 99 · 84 · 513 · 297
3. **المؤلفون** — أسماء يعرفها الزائر
4. **المشكلة** — خمس حالات يشوف نفسه في واحدة منها
5. **المجلدات الستة** — وش يحصل عليه
6. **من وين تبدأ؟** — اختبار يربط حالته بمجلد محدّد
7. **القاعدة الذهبية** — عيّنة حقيقية من داخل الملفات
8. **القائمة كاملة** — 99 عنوانًا بمؤلفيها + دعوة شراء
9. **المحطات الخمس** — المنهج
10. **المقارنة** — البكج مقابل البدائل (بما فيها اللي ما نتفوّق فيه)
11. **قبل/بعد** — النتيجة الواقعية
12. **احسبها بنفسك** — 5,445 ريالًا و594 ساعة مقابل 99 + دعوة شراء
13. **البونصات** → **الآراء** → **العرض** → **الضمان**
14. **الناشر** → **الأسئلة (14 سؤالًا)** → **الختام**

ومعها: شريط علوي لتقدّم القراءة، شريط سفلي لاصق بالسعر والعدّاد، نافذة دفع،
ونافذة مغادرة (مرة واحدة في الجلسة).

## ✍️ ملاحظات على المحتوى

- الصفحة تقول صراحة إن الخلاصة **مو بديلًا عن الكتاب**، وجدول المقارنة يعترف
  إن الكتاب الأصلي أعمق. هذا الاعتراف يرفع الثقة في بقية الادعاءات.
- أرقام قسم «احسبها بنفسك» تقديرية ومكتوب أساس حسابها تحت كل بطاقة
  (55 ريالًا متوسط سعر الكتاب · 6 ساعات متوسط القراءة).
- نافذة الدفع تشرح **وش يصير بعد الضغط** في ثلاث خطوات — أكبر سبب للتردّد
  في اللحظة الأخيرة هو الغموض، مو السعر.
- وسائل الدفع معروضة كشارات لا كأزرار، لأن الاختيار الفعلي يتم داخل صفحة
  Buy Me a Coffee.
